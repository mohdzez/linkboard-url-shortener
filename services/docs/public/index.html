🚀 Linkboard — Docs

A small demo deployed with Liftoff to show a multi-component app on one canvas.

Components

  • api — Express service: create short links, redirect, click tracking, CSV export.
  • web — server-rendered dashboard (this is the page at /app).
  • worker — drains the Redis click queue into Postgres.
  • cron — nightly job that prunes old links.
  • docs — this static site.

Resources

PostgreSQLRedisSpaces (S3)

Connected to the services on the canvas — drawing an edge auto-injects DATABASE_URL, REDIS_URL and SPACES_*.

Try it

  • Open /app for the dashboard.
  • POST /api/links with { "url": "https://example.com" }.
  • Visit /<code> to be redirected (and counted).
  • GET /api/export writes a CSV to the Spaces bucket.

Built with Next.js · NestJS · Pulumi · DigitalOcean — deployed via Liftoff.
